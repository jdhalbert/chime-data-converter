Chime, Marcus & X Money Transaction to CSV Converter

Paste a full transaction JSON payload, or upload/paste a saved HTML page from X Money. Processing is done in your browser. No data leaves your machine.

Chime: Go to chime.com, press F12, and log in. In the Network → Fetch/XHR tab, find the graphql response that contains JSON-formatted transaction data.

Marcus: Go to marcus.com, press F12, and load the page with transaction detail. In the Network → Fetch/XHR tab, find the response called cos/?operations=Transations.

X Money (JSON): Go to x.com/i/money (or the Money tab in the X app web view), press F12, and open Network → Fetch/XHR. Find a GraphQL response whose JSON contains data.get_transactions.items and copy the entire response body.

X Money (HTML): On the X Money transactions page, save the page as HTML (Complete) via your browser's Save Page As, or copy the full page source. Then upload the .html file below or paste its contents into the text box. The tool extracts the visible transaction list (dates, payees, amounts, notes).
