Chime, Marcus & X Money Transaction JSON to CSV Converter

Paste a full transaction JSON payload from any of the supported sources. Processing is done in your browser. No data leaves your machine.

Chime: Go to chime.com, press F12, and log in. In the Network → Fetch/XHR tab, find the graphql response that contains JSON-formatted transaction data.

Marcus: Go to marcus.com, press F12, and load the page with transaction detail. In the Network → Fetch/XHR tab, find the response called cos/?operations=Transations.

X Money: Go to x.com/i/money (or the Money tab in the X app web view), press F12, and open Network → Fetch/XHR. Find a GraphQL response whose JSON contains data.get_transactions.items and copy the entire response body.
